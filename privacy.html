Privacy Policy

Last updated: 12 November 2026

About

shankhaamrit.com is the website of the Shankha Amrit YouTube channel (Kerala temple stories and Pauranik Katha), run by Santosh Roy. The site lists our videos and links to YouTube.

Information we collect on this website

This website has no sign-up, comments, forms or advertising, and it does not set its own cookies. Pages are served by GitHub Pages, which may keep standard server logs (such as IP address and browser type) for security and operations. Fonts are loaded from Google Fonts, and video thumbnails from YouTube, under their own privacy policies.

Shankha Replies (YouTube comment tool)

"Shankha Replies" is a private tool used only by the channel owner to manage the Shankha Amrit channel. With the owner's permission, it uses the YouTube Data API to read public comments on the channel's videos and to post the channel's replies. It does not access any other user's account. Comment data is used only for replying, is not sold or shared, and is not used for advertising. Login tokens are stored only on the owner's computer, and access can be revoked at any time at myaccount.google.com/permissions.

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
